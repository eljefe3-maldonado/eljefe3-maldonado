### 👋 Overview

I'm a **Cloud Architect and Platform Engineering professional with a strong cloud security background**, focused on designing, automating, securing, and operating AWS environments at scale.

I build systems where **security is an engineering outcome** — embedded directly into cloud architecture, infrastructure patterns, CI/CD pipelines, and platform guardrails rather than bolted on after deployment.

Core focus areas:

- **Secure cloud architecture** — AWS-native services, Zero Trust concepts, multi-account governance, and resilient infrastructure design
- **Platform engineering** — repeatable infrastructure patterns, automation workflows, and operationally maintainable cloud foundations
- **DevSecOps** — security-as-code integrated into CI/CD pipelines from the start
- **Immutable infrastructure** — hardened, versioned AMIs using Packer and Ansible
- **Infrastructure as Code** — repeatable, auditable Terraform deployments
- **Cloud-native platform engineering** — Kubernetes, containers, EKS concepts, RBAC, and network policy fundamentals
