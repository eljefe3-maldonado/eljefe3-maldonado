### 👋 Overview

This portfolio demonstrates **hands-on cloud platform engineering** with a focus on building, automating, and operating AWS infrastructure at scale.

Projects emphasize:

- **Immutable infrastructure** using Packer and Ansible  
- **Infrastructure as Code** with Terraform  
- **CI-driven automation** using GitHub Actions and OIDC (no static credentials)  
- **Operational ownership**, including validation, versioning, and rollback strategies  

Security and compliance are treated as **engineering outcomes**, embedded directly into build pipelines and infrastructure design rather than managed as separate processes.
